### Behavioral compatibility

- Legacy write endpoints retain `bid`/`bids_remaining` and `queued` response shapes. Their audit events now follow the shared submission path: Freelancer `proposal_submitted`, browser handoff `proposal_queued`; details use `proposal_id`.
- Worker completion requests must send explicit `success`; the bundled worker already does. Missing or malformed values return 422.
- Uncertain submissions require a recorded platform check. Recovery never dispatches directly; a negative reconciliation requires another approval.
- Write retries now fail on transient errors instead of potentially repeating external actions. This deliberately prioritizes duplicate prevention over automatic recovery.
- No live task replay, proposal submission, email, deployment or production database migration was performed.
