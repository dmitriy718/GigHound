# September 13, 2026 — Live discovery repair and local deployment

## Confirmed incident
The previously opened local Docker stack was an older image. Its database contained one old Upwork job. Scheduled discovery ran but skipped sources: stored Upwork browser credentials were not an API token, Freelancer had no credentials, and the LinkedIn provider had no key. Opening the old stack did not qualify production readiness.

## Implemented
- Freelancer active-project search can use its public GET endpoint when no credential record exists. Authenticated calls retain authentication; rejected authenticated calls do not fall back anonymously. Private reads and writes still require credentials.
- Public responses require a successful API envelope, a projects list, and valid project identities. Public owner metadata is merged when supplied; omitted owner details remain unknown.
- Upwork reports browser-only credentials as unsuitable for API discovery.
- HTTP/malformed-source failures are isolated so another source can succeed.
- Manual search returns ingestion counts and failed platforms. The UI reports completion instead of incorrectly claiming an inline search was queued. A run with no searched source is not success.
